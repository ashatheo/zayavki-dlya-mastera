Политика обработки персональных данных

1. Общие положения

1.1. Настоящая Политика определяет условия обработки персональных данных пользователей сайта «Заявки для мастера» (далее — Сайт).

1.2. Сайт предоставляет информацию об услугах по созданию сайтов и настройке рекламы для мастеров по ремонту бытовой техники, а также форму для заявки на сотрудничество.

2. Обработка персональных данных

2.1. Заполняя форму заявки на Сайте, Пользователь предоставляет свои персональные данные (имя, номер телефона, город, описание рода деятельности) и даёт согласие на их обработку в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ «О персональных данных».

2.2. Целью обработки персональных данных является связь с Пользователем для обсуждения условий сотрудничества.

2.3. Обработка персональных данных осуществляется с использованием и без использования средств автоматизации, включает сбор, запись, систематизацию, хранение, уточнение и использование данных в объёме, необходимом для указанной цели.

2.4. Персональные данные хранятся не дольше срока, необходимого для обработки заявки, если иное не предусмотрено законодательством РФ.

2.5. Пользователь вправе в любой момент отозвать согласие на обработку персональных данных, направив соответствующее уведомление на контактные данные, указанные на Сайте.

2.6. Отправка формы заявки с проставленной отметкой о согласии означает, что Пользователь ознакомился с условиями обработки персональных данных, указанными в настоящем разделе, и выражает своё согласие на такую обработку.

3. Передача данных сторонним сервисам

3.1. Форма обратной связи на Сайте технически реализована через сторонний сервис (Telegram Bot API), который передаёт данные Пользователя администратору Сайта. Обработка данных на стороне этого сервиса регулируется его собственной политикой конфиденциальности.

4. Использование файлов Cookie и аналитика

4.1. Сайт может использовать файлы cookie и собирать информацию об IP-адресах, типе браузера и местоположении пользователей в технических и аналитических целях.

4.2. Эти данные необходимы для обеспечения корректной работы Сайта, анализа пользовательского опыта и улучшения рекламных кампаний.

4.3. Если Пользователь не согласен с использованием файлов cookie, он должен прекратить использование Сайта или отключить сохранение cookie в настройках своего браузера.

5. Заключительные положения

5.1. Продолжая использование Сайта или заполняя форму заявки, Пользователь подтверждает, что ознакомился с настоящей Политикой и полностью принимает её условия.
